    LECTURE. Le modele de vrillage est ACTIVE et l'angle vaut
    7,5 deg, mais le nombre de TRANCHES vaut UN. Or le vrillage
    multi-tranches se represente par la rotation RELATIVE des
    tranches les unes par rapport aux autres : avec une seule
    tranche il n'y a aucune rotation relative, donc aucun
    moyennage axial. La solution de champ est celle d'une section
    droite NON VRILLEE.
    RESERVE : cette lecture repose sur la semantique du modele
    multi-tranches, non sur un run de controle. Un run avec
    UseSkewModel = false donnerait la confirmation directe ; il
    exige ANSYS et reste a faire. La lecture est neanmoins
    suffisante pour ce qui suit, car elle va dans le sens de
    l'affirmation du manuscrit, non contre elle.

    CONFLIT DE DOCUMENTATION A CORRIGER. L'en-tete de
    +mec\ansys_ref.m annonce "skew 7,5 deg / 5 tranches". Le projet
    en declare UNE. L'un des deux est faux, et c'est l'en-tete :
    il n'y a pas d'autre projet 18,5 kW dans le dossier.
